RENDERSYSTEM MODULE — TECHNICAL REFERENCE
================================================================================
C++20 module "Graphics". Deferred/forward hybrid renderer built on the
FrameGraph task-graph architecture. Covers: assets, materials, scene, camera,
mesh rendering, effects, GUI, tiled textures, font, and the full pass pipeline.

Pass  (base)
  Abstract render/compute task node.
  - active() -> bool
  - get_type() -> HAL::CommandListType
  - uint32_t pass_index, GetPassIndex()   slot index for multi-instance passes
  Members:
    wstring name
    PassFlags flags                  General | Compute | Required
    set<Pass*> prev_passes, next_passes

PassFlags enum: General, Compute, Required

Graph
  Main FrameGraph manager.
  - add_library_pass<T>(setup, render, flags)         single-slot pass
  - add_library_pass<T>(index, setup, render, flags)  indexed slot; stamps
                                                       pass->pass_index = index
                                                       resolves T::Names[index]
  - get_context<T>() -> T&     type-keyed UniversalContext store
  - set_slot(SlotID, context)  bind slot data

TaskBuilder
  Resource declaration during setup phase.
  - create(handler, desc, flags)   allocate GPU resource
  - need(handler, flags)           declare read dependency
  - exists(handler) -> bool        check resource exists this frame
  - pass_texture()                 import external texture
  - reset()
  Members:
    Pass* current_pass
    Graph* graph
    set<ResourceInfo*> passed_resources

FrameContext
  Per-pass execution context during render phase.
  - get_list() -> HAL::CommandList::ptr&   lazy-allocate command list
  - begin(), end()                         lifecycle; handles state transitions
  Members:
    Pass* pass
    HAL::FrameResources* frame
    Graph* graph
    HAL::CommandList::ptr list

ResourceAllocInfo
  Tracks per-resource read/write history for barrier scheduling.
  - add_pass(Pass*, ResourceFlags)   register pass using resource
  - remove_inactive()                prune disabled passes
  - reset()
  Members:
    vector<ResourceRWState> states
    set<Pass*> related, related_read

ResourceRWState
  Single R/W phase: bool write, vector<Pass*> passes/graphics/compute,
  Pass* from / to.

Handlers  (resource handle types)
  Handlers::Texture          2D GPU resource handle
  Handlers::Texture3D        3D GPU resource handle
  Handlers::Buffer           GPU buffer handle
  All support: create(desc, flags), need(flags), is_changed() -> bool

PassDefault<T>  (traits struct; declared in pass_defaults.h, bodies handwritten)
  template<> struct PassDefault<Passes::Foo> {
    static constexpr bool enabled = true;
    static constexpr PassFlags flags = ...;
    static bool setup(Passes::Foo::Context&, TaskBuilder&);
    static void render(Passes::Foo::Context&, FrameContext&);
  };
  setup() returns false to cull pass. render() only called if setup returned true.
  All state via graph contexts; no captured instance state.


================================================================================
  MAIN PIPELINE  (Pipelines::MainPipeline)
================================================================================

Defined in test.sig. Execution order:

  [Static]  PreScene                  TLAS update + RTX::prepare
            BlueNoise                 supply blue noise textures
            Voxelize                  voxel scene rasterisation
            PSSM_Global               global shadow camera setup
            PSSM_Cascade[4]           per-cascade shadow map rendering
            CubeSky                   render sky to cube face
  [Static]  CubeMapDownsample         cube mip generation (when sky changes)
  [Static]  CubeMapEnviromentProcessor specular + diffuse IBL filtering
            Lighting                  deferred light accumulation
            Mipmapping                MipMapGenerator pass
  [Static]  Scene                     GBuffer rasterisation via MeshRenderer
  [Static,C] RTXPass                  work-graph ray traced shadows
  [Static]  ResultCreation            allocate R16G16B16A16 result texture
            PSSM_GenerateMask         shadow mask generation
            PSSM_Combine              combine cascades
            VoxelScreen               screen-space voxel GI lookup
            VoxelCombine              blend voxel GI into lighting
            ScreenReflection          SSR ray marching
            ReflectionDenoiser_Reproject reprojection filter
            ReflCombine               compose reflections
            VoxelDebug                optional voxel visualisation
            Sky                       sky composite
            stencil_renderer_before   GUI stencil (before UI)
            stencil_renderer_after    GUI stencil (after UI)
            SMAA                      subpixel morphological AA
  [Static,C] FSR                      AMD FidelityFX upscaling
  [Static,C] CopyPrev                 copy normals/specular/depth → prev buffers
  [Static,R] Profiler                 GPU timing
  [Static,M] UI_Render[16]            UI draw batches (up to 16 slots)

  [Static]   = uses PassDefault<>; no pipeline member
  [C]        = PassFlags::Compute
  [R]        = PassFlags::Required
  [M]        = Multiple=16


================================================================================
  MESH RENDERING
================================================================================

mesh_renderer
  Two-stage GPU occlusion culling + dispatch pipeline.
  render(MeshRenderContext::ptr, Scene::ptr):
    Stage 1 (coarse): init_dispatch → generate_boxes → draw_boxes →
                      gather_rendered_boxes → HiZ downsampling
    Stage 2 (fine):   render_meshes with surviving instances
  - init_dispatch()           reset indirect counter
  - generate_boxes()          compute AABBs on GPU
  - draw_boxes()              rasterise AABBs into occlusion buffer
  - gather_rendered_boxes()   read back GPU culling results
  - render_meshes()           execute final mesh indirect dispatch
  Members:
    HAL::StructuredBufferView<IndirectDispatch> dispatch_buffer
    commands_buffer[8]        per-pipeline indirect command buffers
    commands_boxes, visible_boxes, meshes_ids, meshes_invisible_ids
    uint32_t instances_count
    bool use_gpu_occlusion

MeshRenderContext
  Per-pass rendering parameters.
  - HAL::CommandList::ptr list
  - GBuffer* g_buffer          deferred render target
  - camera* cam
  - size_t current_time
  - TaskPriority priority

main_renderer
  Coordinator; owns a list of sub-renderers (e.g. mesh_renderer).
  - register_renderer(shared_ptr<sub>)
  - render(MeshRenderContext::ptr, Scene::ptr)

GBuffer  (resource group)
  All GBuffer textures referenced together.
  albedo, normals, specular, speed (motion), depth, depth_mips,
  depth_prev_mips, HalfBuffer (hiZ_depth, hiZ_depth_uav),
  compiled (RT::GBuffer), HalfBuffer.compiled (RT::DepthOnly).

GBufferViewDesc
  - static create(size, data, builder)         standard GBuffer
  - static create_mips(size, data, builder)    mip chain
  - static create_quality(size, data, builder) quality color
  - static actualize(data) -> GBuffer          materialise handles into GBuffer

================================================================================
  EXECUTION FLOW SUMMARY
================================================================================

1. Frame start
     MainPipeline::add_passes(graph) — register all passes (static inline,
     dynamic via setup/render func members)

2. Graph setup phase  (for each registered pass in order)
     Pass::setup(Context&, TaskBuilder&)
       — declare resources (create / need)
       — return false to cull pass
     Resources allocated; barriers computed from ResourceAllocInfo R/W graph

3. Scene update  (inside PassDefault<PreScene>::render)
     Scene::update() — compile SceneData, command ID lists, material GPU data
     TLAS update (raytrace_scene->update) if RTX supported
     RTX::get().prepare()

4. Render phase  (for each surviving pass in dependency order)
     Pass::render(Context&, FrameContext&)
       — record into CommandList via ComputeContext / GraphicsContext
       — resource states auto-transitioned by FrameContext lifecycle

5. Mesh pass  (PassDefault<Passes::Scene>::render)
     MeshRenderer two-stage occlusion:
       init_dispatch → generate_boxes → draw_boxes →
       gather_rendered_boxes → render_meshes → HiZ

6. Effects sequence  (subsequent passes)
     Lighting → VoxelGI → Sky → RTXPass → ShadowDenoiser →
     ScreenReflection → ReflectionDenoiser → FSR → SMAA

7. UI  (stencil_renderer_before → UI_Render[0..N] → stencil_renderer_after)
     draw_infos batched from UIContext; each slot renders a contiguous range

8. Frame end
     CopyPrev — copy temporal buffers
     Profiler — resolve GPU timestamps
