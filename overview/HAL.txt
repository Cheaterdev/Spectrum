HAL MODULE — TECHNICAL REFERENCE
================================================================================
D3D12-based Hardware Abstraction Layer.
Covers: resources, queues, command lists, descriptors, PSOs, raytracing,
tiled memory, frame management, shaders, and the autogenerated PSO library.


================================================================================
  RESOURCE STATES
================================================================================

ResourceState
  Encapsulates D3D12 barrier sync, barrier access, and texture layout in one
  value. Supports |, |=, &, &= for combining.
  - has_write_bits()          true if state has any write access
  - is_no_access()            true for NO_ACCESS sentinel
  - is_valid(ResourceType)    validate state/type compatibility
  - valid_begin()             valid as initial frame state
  - get_best_cmd_type()       returns DIRECT/COMPUTE/COPY — cheapest queue

ResourceStates namespace — predefined constants:
  INDEX_BUFFER, COPY_SOURCE, COPY_DEST, SHADER_RESOURCE, UNORDERED_ACCESS,
  RAYTRACING_STRUCTURE, RAYTRACING_STRUCTURE_WRITE, INDIRECT_ARGUMENT,
  RENDER_TARGET, DEPTH_STENCIL, NO_ACCESS, UNKNOWN.

SubResourcesCPU
  CPU-side per-subresource tracking: first/last usage, state history.
  - merge_read_state()
  - get_subres_state(int)

ResourceStateManager
  Manages D3D12 resource transitions across command lists.
  - transition(Transitions*, ResourceState, uint subres)
  - prepare_state()        — merge GPU/CPU state at frame start
  - process_transitions()  — pre-transitions between frame boundaries
  - connect()              — connects transitions between command lists
  - alias_begin/end()      — aliasing barrier handling

Barriers
  Accumulates resource barriers for batch submission.
  - transition(from, to)
  - validate()
  - get_barriers()

Transitions
  Per-command-list resource usage tracking.
  - add_usage(), get_last_usage_point(), track_object(), use_resource()


================================================================================
  RESOURCES
================================================================================

ResourceDesc
  Describes a GPU resource. Factory methods:
  - Buffer(size, flags)
  - Tex1D/Tex2D/Tex3D(format, dims, arraySize, mipLevels, flags)
  Properties: Width, Height, DepthOrArraySize, MipLevels, Format, Flags,
              Dimension.
  - is_buffer(), is_texture(), is_virtual(), as_texture()
  - CalcSubresource(mip, slice)

Resource     (shared_ptr alias: Resource::ptr)
  Base class for all GPU resources.
  - Constructors: from native D3D12 resource, from ResourceDesc + heap type,
    from ResourceHandle.
  - native_resource          underlying ID3D12Resource
  - desc                     ResourceDesc
  - heap_type                HeapType (DEFAULT, UPLOAD, READBACK, RESERVED)
  - write(GPUBinaryData)     upload via DirectStorage
  - get_resource_address()   D3D12 GPU virtual address
  - get_tiled_manager()      TiledResourceManager* for sparse resources
  - get_desc()               resource properties

Buffer : Resource       — buffer-specific ops
TextureResource : Resource  — texture-specific ops

Texture
  User-facing texture wrapper around TextureResource.
  - Constructors: (D3D12 native, layout), (ResourceDesc, layout)
  - get_data()               readback to texture_data (CPU)
  - upload_data(ptr)         upload from texture_data
  - get_size(mip)            ivec2 mip dimensions
  - is_rt()                  render target flag
  - compress()               compress texture data
  - Static: create(texture_data::ptr)
  - Views: cube_view, texture_2d_view, texture_3d_view, feedback

HeapType enum: DEFAULT, UPLOAD, READBACK, RESERVED


================================================================================
  FENCE / SYNCHRONIZATION
================================================================================

Fence
  - Fence(Device&)
  - signal(value)              GPU signal
  - get_completed_value()      current completed value
  - wait(value)                CPU block until value reached
  Member: m_fence (ID3D12Fence*)

Event
  - wait()                     CPU block (WaitForSingleObject)
  Lifetime: CreateEventEx / CloseHandle

FenceWaiter   (RAII)
  - operator bool()            valid check
  - wait()                     block CPU until fence value reached
  Stores: Fence*, value, CommandListType


================================================================================
  QUEUE
================================================================================

Queue  (one per CommandListType: DIRECT, COMPUTE, COPY)
  Constructor: Queue(CommandListType, Device*)

  Resource acquisition:
  - get_free_list()            get/create CommandList from pool
  - get_transition_list()      get/create TransitionCommandList from pool

  Submission:
  - execute(list<CommandList::ptr>) -> FenceWaiter   submit and return waiter
  - signal() -> FenceWaiter          GPU fence signal
  - signal_and_wait()                submit + CPU wait (hard sync)
  - gpu_wait(FenceWaiter)            GPU-side wait on another queue's fence

  Misc:
  - is_complete(UINT64 fence)        check fence completion without blocking
  - run(function<void()>)            enqueue CPU-side callback
  - update_tile_mappings()           update sparse/tiled resource tile mappings
  - execute_internal()               internal: execute + signal + handle tiles

  Threading: two worker threads (gpu_execute_thread, gpu_wait_thread) for
  async GPU operations; all public methods are thread-safe via mutex.


================================================================================
  COMMAND LIST
================================================================================

CommandList   (module HAL:CommandList)
  High-level command recording. Internally uses DelayedCommandList.

  Constructor: CommandList(CommandListType)
  Members:
    name                    wstring debug label
    type                    CommandListType
    active                  currently recording?
    current_pipeline        active PSO
    debug_buffer            StructuredBufferView for shader debug output
    frame_resources         FrameResources*
    tile_updates            list<tile_update_info>

  Context accessors (only valid after begin()):
    get_compute()           ComputeContext
    get_copy()              CopyContext
    get_graphics()          GraphicsContext (DIRECT type only)

  Lifecycle:
    begin(name)             start recording
    execute()               compile DelayedCommandList and submit
    execute_and_wait()      execute + CPU wait

  Debug:
    setup_debug(SignatureDataSetter*)
    print_debug()           read back and log debug buffer
    GPU timing via GPUBlock/GPUTimer

DelayedCommandList  (API::CommandList)
  Stores recording as vector<function<void(API::CommandList&)>>.
  compile(CommandAllocator&)  — replays all stored lambdas onto native list.
  reset()                     — clear compiled state.

  All recording methods queue lambdas:
    clear_uav/rtv/stencil/depth()
    set_pipeline(), set_graphics/compute_signature()
    set_topology(), set_stencil_ref()
    draw(), draw_indexed(), dispatch(), dispatch_mesh()
    set_index_buffer(), set_descriptor_heaps()
    copy_resource(), copy_buffer(), copy_texture()
    update_texture(), read_texture()
    build_ras()                  raytracing AS build
    set_rtv(), set_viewports(), set_scissors()
    start_event(), end_event()   PIX markers
    set_program(), dispatch_graph()   work graphs
    graphics/compute_set_const_buffer(), graphics/compute_set_constant()
    execute_indirect()
    insert_time(), resolve_times()   GPU timestamp queries

TransitionCommandList
  Specialized CommandList for inter-frame resource state transitions only.

CommandAllocator
  - CommandAllocator(CommandListType)
  - create()      allocate native ID3D12CommandAllocator
  - reset()       recycle for reuse
  - get_type()    CommandListType


================================================================================
  CONTEXT CLASSES
================================================================================

Three context objects are accessed from CommandList. Each exposes a domain-
specific subset of D3D12 recording operations.

ComputeContext
  dispatch, UAV clears, compute root signature/constants binding.

CopyContext
  copy_resource, copy_buffer, copy_texture, read_texture, update_texture,
  texture layout queries.

GraphicsContext
  draw, draw_indexed, set_topology, clear_rtv/dsv, render target binding,
  viewport/scissor setup, root signature binding.


================================================================================
  DEVICE
================================================================================

Device  (main GPU device; Singleton)
  Construction: create_singleton() selects best DXGI adapter.

  Initializes:
    - Feature detection: is_rtx_supported(), mesh shaders, bindless, work
      graphs, GPU upload heaps.
    - One Queue per CommandListType.
    - HeapFactory, DescriptorHeapFactory, QueryHeapFactory.
    - FrameResourceManager, StaticCompiledGPUData.
    - PipelineStateCache, EnginePSOHolder.
    - DirectStorageQueue.

  Key accessors:
    get_queue(CommandListType)        Queue*
    get_upload_list()                 convenience: DIRECT queue list
    get_frame_manager()               FrameResourceManager
    get_heap_factory()                HeapFactory
    get_descriptor_heap_factory()     DescriptorHeapFactory
    get_query_heap_factory()          QueryHeapFactory
    get_static_gpu_data()             StaticCompiledGPUData
    get_pipeline_state_cache()        PipelineStateCache
    get_engine_pso_holder()           EnginePSOHolder (pre-compiled PSOs)
    get_ds_queue()                    DirectStorageQueue
    get_native_device()               ID3D12Device*

  Methods:
    get_alloc_info(ResourceDesc)      size + alignment for resource
    get_texture_layout()              subresource layout for uploads
    compress(span<byte>)              DirectStorage compression
    get_vram()                        VRAM usage
    get_ca(CommandListType)           CommandAllocator from pool
    free_ca()                         return allocator to pool
    calculateBuffers()                raytracing prebuild info
    stop_all()                        drain all queues, shutdown

  DeviceProperties flags:
    rtx_supported, mesh_shader, full_bindless,
    direct_gpu_upload_heap, work_graph


================================================================================
  DESCRIPTORS
================================================================================

Handle
  Reference to a descriptor slot in a heap.
  - is_valid() / operator bool()
  - get_offset()
  - get_gpu() / get_cpu()       D3D12_GPU/CPU_DESCRIPTOR_HANDLE
  - get_resource_info()         ResourceInfo in heap
  - place(Handle&)              copy descriptor from another handle

Strongly-typed handles: RTVHandle, DSVHandle, UAVHandle
(CBV, SRV, UAV, RTV, DSV, SMP for sampler)

DescriptorHeap
  - DescriptorHeap(Device&, uint count, DescriptorHeapType, DescriptorHeapFlags)
  - resources    vector<ResourceInfo>
  - descriptor_size, num

ResourceInfo
  - for_each_subres(function<void(Resource::ptr&, uint)>)
  - Stores one of: ShaderResource, UnorderedAccess, RenderTarget,
    DepthStencil, ConstantBuffer view variant

Views::ShaderResource variants:
  Buffer, Texture1D, Texture1DArray, Texture2D, Texture2DArray,
  Texture2DMS, Texture2DMSArray, Texture3D, Cube, CubeArray, Raytracing

Views::UnorderedAccess variants:
  Buffer (optional counter), Texture1D, Texture1DArray,
  Texture2D, Texture2DArray, Texture3D

Views::RenderTarget variants:  Texture2D, Texture2DArray
Views::DepthStencil variants:
  Texture1D, Texture1DArray, Texture2D, Texture2DArray, Texture2DMS,
  Texture2DMSArray

Views::ConstantBuffer: single resource CBV

================================================================================
  ROOT SIGNATURES
================================================================================

RootSignature
  - RootSignature(Device&, RootSignatureDesc&)
  - Compiles to native ID3D12RootSignature.
  - Types: Global (graphics/compute), Local (raytracing).
  - Supports bindless / volatile descriptors.

RootSignatureDesc
  - parameters    map of parameter definitions
  - samplers()    static sampler accessors
  - type          RootSignatureType

Parameter types in a root signature:
  DescriptorConstants     inline root constants
  DescriptorTable         table with range (CBV/SRV/UAV)
  DescriptorConstBuffer   root CBV
  DescriptorSRV           root SRV
  DescriptorUAV           root UAV


================================================================================
  PIPELINE STATES
================================================================================

PipelineStateDesc  (graphics)
  Shaders: vertex, pixel, hull, domain, geometry, mesh, amplification (ShaderRef)
  root_signature, rtv (RenderTargetViewDesc), blend (BlendDesc[]),
  rasterizer (RasterizerDesc), topology (PrimitiveTopologyType)

ComputePipelineStateDesc
  root_signature, shader (ShaderRef), name

PipelineState  (compiled graphics PSO)
  - Static factory: create(PipelineStateDesc&, name) — hits PipelineStateCache
  - get_tracked()         tracking info for indirect rendering
  - register_shader()     file dependency tracking

ComputePipelineState  (compiled compute PSO)
  Same pattern as PipelineState.

StateObject  (raytracing / work graph)
  - StateObjectType::WorkGraph
  - libraries, global_root signature

PipelineStateCache
  - LRU cache (graphics + compute) keyed by PipelineStateDesc hash.
  - binary_cache: persists compiled PSO blobs to cache/pso.bin on shutdown.
  - Thread-safe via mutex.

PSO definition macros (PSO_defines.h):
  GEN_COMPUTE_PSO(name, ...)    — emits class with create(Device&), GetPSO()
  GEN_GRAPHICS_PSO(name, ...)
  GEN_WORKGRAPH_PSO(name, ...)

EnginePSOHolder
  Holds one instance of each PSO class. GetPSO<T>() returns compiled PSO.


================================================================================

================================================================================

Shader<T>  — one per shader stage
  Specializations: pixel_shader, vertex_shader, geometry_shader,
  domain_shader, hull_shader, compute_shader, mesh_shader,
  amplification_shader, library_shader.
  - compile_code(HLSL 5.1)
  - compile_code_dxil(DXIL 6.8)

ShaderRef
  - file_name, entry_point, flags (ShaderOptions)
  ShaderOptions: FP16, Debug, WaveOps (wave64)

shader_macro
  - shader_macro(name, value = "1")   — preprocessor define

shader_include
  - shader_include(dir, resource_file_depender&)
  - load_file(string)   — resolve #include, track dependency
  - Tracks autogen includes separately


================================================================================
  RAYTRACING
================================================================================

RaytracingAccelerationStructure
  BLAS constructor: (vector<GeometryDesc>, CommandList::ptr)
  TLAS constructor: (vector<InstanceDesc>)
  - update(CommandList::ptr, UINT size, ResourceAddress instances,
           bool need_rebuild)   rebuild or refine TLAS
  - get_gpu_address()           D3D12 address for use in shaders
  - raytracing_handle           descriptor handle for SRV binding
  Members:
    scratch_buffer              temporary build buffer
    cur_buffer / prev_buffer    current/prev structure buffers
    currentResource / prevResource   virtual buffers for TLAS

GeometryDesc   — triangle mesh with vertex/index buffer refs
InstanceDesc   — transform matrix, instance ID, geometry index

RaytracingBuildDescStructure
  DestAccelerationStructureData, ScratchAccelerationStructureData,
  SourceAccelerationStructureData (update source)

RaytracingBuildDescBottomInputs / RaytracingBuildDescTopInputs
  Geometry / instance input specification for builds


================================================================================
  TILED (VIRTUAL) MEMORY
================================================================================

TiledResourceManager
  Manages sparse/virtual textures — maps 64 KB tiles on demand.
  Constructor: TiledResourceManager(Resource*)
  - load_tile(update_tiling_info&, uint3 pos, uint subres, bool recursive)
  - zero_tile()              unmap tile (back to null tile)
  - load_tiles(range)        load a range of tiles
  - load_buffer_part()       load 64KB-aligned buffer range
  - load_packed()            load packed mip (parent mip for small mips)
  Callbacks: on_load(), on_zero() — user notification
  Members:
    tiles          3D map<subresource, ResourceTile> by coordinate
    tile_heap_type HeapType backing tiles
    resource       owning Resource*

ResourceTile
  - pos              uint3 tile coordinate
  - subresource      mip level
  - heap_position    TileHeapPosition (heap buffer, offset, count)

TileHeapPosition
  - heap    Buffer* backing storage
  - offset  tile offset in heap (64KB units)
  - handle  AllocatorHandle for freeing
  - count   number of tiles in allocation

update_tiling_info
  Batched tile map operation sent to Queue::update_tile_mappings().
  - tiles     map<heap, tile_list>
  - resource  target sparse resource
  - add_tile(ResourceTile)


================================================================================
  FRAME MANAGEMENT
================================================================================

FrameResourceManager
  - begin_frame() -> FrameResources*   returns resources for current frame

FrameResources
  Per-frame GPU allocations; recycled each frame.
  - start_list(name, CommandListType) -> CommandList::ptr
  - free_ca()    return command allocator to frame pool
  - frame_number

GPUEntityStorageInterface
  - aquire_data(uploadSize, heap_type, alignment, offset)
    allocate frame-lifetime GPU buffer space (upload heap)
  - create_tile(HeapType, UINT count)
    allocate tiled resource backing memory
  - alloc_memory()

StaticCompiledGPUData
  Engine-global persistent GPU allocations (not per-frame).
  Same allocation interface as FrameResources.

================================================================================
  D3D12 NATIVE LAYER  (namespace API)
================================================================================

API::Device
  - init(DeviceDesc&)         create ID3D12Device, check feature support
  - get_native_device()       ID3D12Device*
  - get_alloc_info()          GetResourceAllocationInfo2
  - compress()                DirectStorage compression
  - get_vram()                QueryVideoMemoryInfo
  Destructor: ReportLiveObjects in debug builds

API::CommandList
  Transient during compilation of DelayedCommandList.
  - begin(CommandAllocator&)  reset + initialize native command list
  - end()                     close native command list
  All recording methods call corresponding D3D12 methods directly.
  Member: m_commandList (ID3D12GraphicsCommandList*)

API::Queue
  - construct(CommandListType, Device*)   create ID3D12CommandQueue
  - execute(CommandListCompiler*)         ExecuteCommandLists
  - gpu_wait(FenceWaiter)                 ID3D12CommandQueue::Wait
  - signal() -> FenceWaiter               Signal
  - update_tile_mappings()                UpdateTileMappings
  Member: native (ID3D12CommandQueue*)

API::RootSignature
  Converts HAL RootSignatureDesc to D3D12 serialized blob.
  Creates ID3D12RootSignature.

API::Fence
  Thin wrapper over ID3D12Fence.
